Before you read

Home Delivery Order

Look at the title and the picture. What kind of text is this?

    This is a home delivery order. It shows what a customer ordered, and when it will arrive.

    There is no time limit and no score. Take your time.

    Read the order

    Read for the main message first.

    Key word help

    Open this if a word is new.

    delivery
    When the shop brings your food to your home.
    order number
    The number that shows which order this is.
    total
    The full amount of money you must pay.
    front door
    The main door of your home.

    Find the main message

    Answer both questions about the order. You can open the order again if you need it.
